# Phil Tainton Racing

Static first-pass redesign for Phil Tainton Racing.

## Files

- `index.html` - homepage markup
- `styles.css` - responsive site styles
- `assets/` - local PTR imagery and logos
- `CODEX.md` - project notes and working memory
- `vercel.json` - Vercel static hosting options

## Preview

Open `index.html` in a browser.

## Deploy

When Git is available, push this folder to `maxwell8686-create/phil-tainton-racing.git` and import the repository in Vercel as a static site.
